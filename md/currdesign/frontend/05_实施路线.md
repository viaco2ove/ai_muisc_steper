## 关键风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 本地模型 `orcg` 不支持 native function calling | ReAct 无法落地 | `LLMRegistry` 按能力路由，不支持则退回 JSON 解析路径；**两条路径共用 EventBus，前端无感** |
| Windows 子进程 kill 不彻底（MuseScore4.exe 等孙进程） | 「停止」按下后进程残留 | `CREATE_NEW_PROCESS_GROUP` + `taskkill /PID xx /T /F`；并在 `task_done` 里如实上报 |
| `GET .../file?path=` 路径穿越 | `?path=../../../.env` 泄露 `minimax_api_key` | `resolve()` 后必须校验仍在工程目录内，否则 403。**上线前必测** |
| 大型工程（52 小节 14 轨）渲染卡顿 | 前端掉帧 | Tab 化按需渲染 + memo + 日志 rAF 合并；ChordTimeline 横向虚拟化 |
| 技能日志刷屏（mscx 生成上千行） | 主线程卡死 | 16ms 批量 flush + 单卡片 500 行上限 |
| 人工编辑与 AI 改写冲突 | 用户编辑被 `song_engineer` 覆盖 | `if_unmodified_since` + 409 + 本地/远端对比选择 |
| WS 协议 v1→v2 切换期 | 新旧事件混乱 | 后端双发 + `LEGACY_TYPE_MAP`；前端 v2 优先 v1 兜底；切完再删 v1 |

## 不做 / 明确砍掉

对齐 `agent_panel.design.md`「砍掉」章节，避免范围蔓延：

- ❌ 多用户 / 权限 / 云端同步 —— 本地单人工具
- ❌ 前端自己解析 MD（删 `utils/mdParser.ts`）—— 后端是唯一解析器
- ❌ 前端跑技能 / 算乐理 —— 全部交后端
- ❌ 完整 shadcn/ui 引入 —— 只按需装 4 个 Radix Primitive
- ❌ 移动端适配 —— 桌面创作工具，最低 1280px
- ❌ 多工作区并行 / 任务队列 —— 本地单任务串行
