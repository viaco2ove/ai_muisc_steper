## DAW 原型（分轨混音 + 逐音符编辑）
`daw.html` 是第二版原型，把「分轨」和「轨道编辑」两个视图按 **DAW（数字音频工作站）形态**重做：

### 左·分轨混音（🎚 Mix）
- 每条轨道一条 lane：头部含 **静音 M / 独奏 S**、**乐器音色 / 歌手声库** chip、**音量推子**、**力度条**（力度按 velocity 着色）。
- lane 右侧是**横向片段时间轴**：用色块直观显示每个音符/片段的位置、时值与力度（人声块显示歌词，乐器块显示音名）。
- 顶部有**主音量**推子；点轨道头部或时间轴即选中并载入右侧编辑器。
- 主唱/和声显示 `Sopranos`/`Altos` 声库；打击乐（14_slap）用红色 chip 区分。

### 右·逐音符编辑器（🎹 Piano Roll + Inspector）
- **钢琴卷帘**：纵轴音高（含黑键底纹），横轴节拍；**拖动音符直接改音高**，点选音符进检查器。
- **检查器**按轨道类型自适应：
  - 人声轨（主唱/和声）：音高/起拍/时值/力度 + **歌词** + **音素表（phoneme，每行可调 ph_dur 占比）** + **对齐方式（自动/吸附/手动）** + **中点分段** + **歌手配置（声库/Tension/Breath/Gender）**。
  - 乐器轨：音高/起拍/时值/力度 + 演奏技法 + 音色 UID；打击乐轨同理。
- 顶部工具条：量化、吸附、播放头分割、试听选中。

> 交互均为前端模拟，改动不回写真实 JSON；音素/ph_dur/对齐等字段结构对应 OpenUtau USTX 的 `phonemes[]` / `ph_dur` / `alignment`。
